Story 1
I want to keep track of all the physical equiptment in my home lab.
The lab has servers,desktop computers, switches, routers, and other equiptment. 
For each device I want to record device name, device type, manufacturer, model, status and location.

Story 2
I want to document the networks used in my home lab.
Each Vlan can have its own subnet and gateway.
I want to know what IP address belongs to what device and what network the address is part of.

Story 3
I use physical servers to run virtual machines. 
I want to keep track of the virtual machines in my lab,including the VM name, operating system, assigned CPU, assinged RAM, and storage.
I also want to keep track of what server is hosting each virtual machine.

Story 4
I also run Docker containers inside my home lab.
These containers provide services like Nginx,Portainer, and Flask dashboard.
I also want to record each container, what host it runs on, what image it uses, what ports are exposes, and if the container is currently runing.

Story 5
I use my home lab for different things. For example I use one as a game server and another for a Devops playground.
I want to document what equiptment ia assosiated with each project and what purpose the equiptment serves.
